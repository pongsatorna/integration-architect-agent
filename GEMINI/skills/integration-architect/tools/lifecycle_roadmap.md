# Integration Lifecycle Roadmap

| Phase | Skill | Primary Input | Primary Output | Gate Requirement |
| :--- | :--- | :--- | :--- | :--- |
| **1. Discovery** | `discovery_expert` | Word (.docx), CSV | OpenAPI Spec, Schema Map | Technical Source Validated |
| **2. Analysis** | `ui_analyzer` | Figma, Screenshot | UI Requirements Spec | User Target Validated |
| **3. Design** | `contract_designer` | Specs from Phase 1 & 2 | Optimized Mobile Contract | Architect Review |
| **4. Align** | `data_aligner` | DB Gap Analysis | SQL DDL, Migration Plan | DBA Approval |
| **5. Verify** | `quality_architect` | Final OpenAPI | Postman, K6, Mocks | Test Coverage Ready |
